# Employee Management System

## Internship Project

This project was developed as part of my Web Development Internship. The Employee Management System is a full-stack web application designed to manage employee records through a simple and user-friendly interface.

The system allows administrators to perform employee management operations such as adding, viewing, updating, and deleting employee information while storing records in a SQLite database.

---

## Project Objective

The objective of this project is to develop a web-based Employee Management System that helps organizations maintain employee records efficiently using a centralized database and an intuitive dashboard.

---

## Features

### Authentication

* Login page with credential validation
* Session protection for dashboard access
* Logout functionality

### Employee Management

* Add new employees
* View employee records
* Edit employee details
* Delete employee records
* Store employee information in SQLite database

### Dashboard

* Display total number of employees
* Display total departments
* Display highest salary among employees
* Navigation panel for quick access

### Department Management

* Dynamic department listing
* Employee count for each department
